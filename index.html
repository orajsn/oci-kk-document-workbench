FIF · Family card processing on OCI

KK Document Workbench

A family card contains several people on one sheet. Open a member’s printed row, compare the national identification number (NIK) with the extracted digits, and record what you can verify.

Try the two-card review

Review a member’s NIK

  1. Choose Open result on Example 02, then Review this NIK. Read the reason above the crop. Use Show full member row to confirm whose number you are checking.
  2. Choose Confirm as printed if the digits match. Choose Correct NIK if the print clearly differs, or Still unreadable if a digit is unclear.
  3. Return to the document list. Open the same card and choose Open decision to see the original reading and the saved decision.

This browser exercise uses two fictional records and saves decisions in this browser. It makes no model calls.

Try a bulk upload on your computer

Download the source and extract it. Open a terminal in the directory containing run_local.py. With Python 3.11 or later, run:

python run_local.py --port 8876 --data-dir runtime/day-one --reference-dir demo/day-one/reader

Open http://127.0.0.1:8876, choose Upload cards and enter LATIHAN under Batch reference. Select Recorded sample and upload both PNGs in demo/day-one/ together.

On card B, compare the second member’s NIK with the print, save a correction and restart the server using the same data directory. The first-batch walkthrough shows how to reopen the correction and compare reread thresholds against the original readings.

Deploy and verify the OCI workflow

The local exercise uses recorded readings and SQLite. In OCI Batam, the worker reads images and stores household records, member rows and review history in Oracle Database. The portable release includes the private operator interface. The hosted participant gateway and staged form-serial rule are managed separately.
